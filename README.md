## 💻 실행 및 빌드

### 개발 서버 실행
```bash
npm run electron:dev
```

### 설치 파일 빌드
```bash
npm run electron:build
```
> 빌드된 설치 파일과 `latest.yml`은 `release-build/` 폴더에 생성됩니다.
